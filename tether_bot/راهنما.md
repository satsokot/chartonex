# راهنمای نصب Chartonex Tether Bot

## پیش‌نیازها
- Python 3.10 یا بالاتر
- اکانت تلگرام
- یک ربات تلگرام (از @BotFather بسازید)
- API Key تلگرام (از my.telegram.org)

---

## نصب (لینوکس / ساب‌دامین)

```bash
cd tether_bot
bash install.sh
```

## تنظیم .env

فایل `.env` را باز کنید و پر کنید:

```
TELEGRAM_API_ID=12345678         ← از my.telegram.org
TELEGRAM_API_HASH=abc123...      ← از my.telegram.org
TELEGRAM_PHONE=+989123456789     ← شماره تلفن اکانت تلگرام

BOT_TOKEN=1234567890:ABC...      ← از @BotFather

SECRET_KEY=هر-رشته-تصادفی       ← خودکار تنظیم می‌شود
ADMIN_USERNAME=admin             ← نام کاربری پنل
ADMIN_PASSWORD=رمز-قوی           ← رمز پنل
```

## اجرا

```bash
bash run.sh
```

پنل ادمین: **http://آدرس-سرور:5000**

---

## تنظیم در پنل ادمین

### ۱. اتصال تلگرام
1. بخش «اتصال تلگرام» را پر کنید
2. «ذخیره و اتصال» را بزنید
3. کد SMS را وارد کنید

### ۲. تنظیم کانال‌ها
- **کانال مبدا:** `@channel_username` (کانال عمومی منبع قیمت)
- **کانال مقصد:** `@your_channel` (ربات باید ادمین آن باشد)

### ۳. آستانه‌ها
- **آستانه اختلاف:** اگر اختلاف قیمت مقصد با میانگین بیشتر از این باشد، ارسال می‌شود (پیش‌فرض: ۳۰۰)
- **مقدار کسر:** از میانگین کم می‌شود (پیش‌فرض: ۱۰۰)

### ۴. فرمول کار
```
میانگین = (خرید + فروش) ÷ ۲
اگر |قیمت_مقصد - میانگین| > آستانه:
    قیمت_ارسالی = میانگین - مقدار_کسر
    ارسال به کانال مقصد
```

### ۵. شروع ربات
دکمه «شروع ربات» را بزنید. ربات هر X دقیقه (قابل تنظیم) اجرا می‌شود.

## نصب به عنوان سرویس (اجرای دائمی)

```bash
sudo bash setup_service.sh
```

## نکات مهم
- ربات باید **ادمین** کانال مقصد باشد
- برای کانال خصوصی مقصد، ID عددی را استفاده کنید (مثل `-1001234567890`)
- اگر دو مرحله‌ای فعال است، رمز را هم وارد کنید
